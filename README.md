# 🔬 Cosmolyze — AI-Powered Cosmetic Analysis Tool

Cosmolyze is an intelligent computer vision and multimodal AI application that analyzes cosmetic product packaging/ingredients, matches formulations, and provides detailed ingredient safety and product comparisons.

---

## 🌟 Core Functionality

- 📸 **Visual Product Identification:** Upload product packaging images for instant detection using AI vision models.
- 🧪 **Ingredient Breakdown & Safety Analysis:** Extracts ingredient lists and flags potential irritants or active compounds.
- 🔄 **Smart Product Matching:** Finds direct market alternatives and budget-friendly formulation dupes.
- ⚡ **Real-Time Insights:** High-speed serverless inference pipeline for smooth user interactions.

---

## 🏗️ Architecture & Tech Stack

- **Frontend:** HTML, CSS, Modern JavaScript
- **Backend / Proxy:** Node.js, Express / Serverless API Functions
- **AI Models:** Multimodal Vision & Text LLMs
- **Deployment:** Vercel Platform
